# 📚 示例一：网文小说章节

## 输入提示词

```
请用 general-writing 技能帮我写一章玄幻小说：
- 主角：陆沉
- 情节：刚刚获得系统，发现系统的过程
- 类型：玄幻、系统流
- 要求：有悬念和爽点，字数2000字左右
```

---

## AI 执行流程

### 🧠 深度分析

- **类型**：玄幻、系统流
- **核心**：主角获得系统那一刻的震撼和期待
- **情绪曲线**：疑惑 → 惊讶 → 狂喜 → 期待
- **爽点**：系统的强大功能、对未来的展望

### 📐 结构规划

1. **开篇**：陆沉处于低谷（被欺辱？修炼失败？）
2. **转折**：突然听到"叮——"的系统提示音
3. **发展**：查看系统面板，发现逆天功能
4. **高潮**：系统发布第一个任务，奖励丰厚
5. **悬念**：任务有风险，接不接？

### ✍️ 优质撰写

**开篇示例**（Show, Don't Tell）：
```
陆沉记得很清楚，他死的那天是晴天。

准确地说，是三秒前。

拳头落下的瞬间，他甚至能闻到对方袖口飘来的檀香味——那是内门弟子才有资格用的熏香。

"外门废物，也配和我争名额？"

声音很轻，带着少年人特有的傲慢。

陆沉想说什么，但喉咙里涌上的腥甜让他所有的话都变成了沉默。

然后世界就黑了。

……

再睁眼时，他正趴在自己的破旧小屋里，面前的木桌上，一本泛黄的古籍正缓缓浮现出一行行血字——

【叮——】
【系统绑定成功。】
【欢迎使用'万古长青系统'，宿主：陆沉。】
```

### 🔍 自我质检

- **逻辑检查**：✅ 系统出现有伏笔（古籍浮现）
- **人物检查**：✅ 陆沉的性格（坚韧、冷静）符合其行为
- **节奏检查**：✅ 开篇抓人，转折合理，发展充实
- **爽点检查**：✅ 有悬念（怎么死的？）、有期待（系统功能？）

## 输出示例（节选）

### 第一章：死过一次才明白

陆沉记得很清楚，他死的那天是晴天。

准确地说，是三秒前。

拳头落下的瞬间，他甚至能闻到对方袖口飘来的檀香味——那是内门弟子才有资格用的熏香。

"外门废物，也配和我争名额？"

声音很轻，带着少年人特有的傲慢。

陆沉想说什么，但喉咙里涌上的腥甜让他所有的话都变成了沉默。

然后世界就黑了。

……

再睁眼时，他正趴在自己的破旧小屋里，面前的木桌上，一本泛黄的古籍正缓缓浮现出一行行血字——

【叮——】

【系统绑定成功。】

【欢迎使用'万古长青系统'，宿主：陆沉。】

陆沉愣住了。

不是因为恐惧，而是因为那一行血字后面，还跟着一串让他心脏骤停的数据——

【当前修为：练气一层（0/100）】
【灵根品质：凡品（已检测至尊神体，是否融合？）】
【系统积分：0（新手任务完成后可获得1000积分）】
【新手任务：在三日内击败王超，证明自己。任务奖励：1000积分 + 神秘大礼包。】

陆沉的目光死死钉在"至尊神体"四个字上。

凡品灵根。

这是压在他头上整整三年的大山，是让他从天才沦为笑柄的元凶，是王超那种纨绔子弟都敢踩他一脚的理由。

而至尊神体……

他咽了口唾沫，手指微微颤抖着，在"是否融合"上点了下去。

【融合开始。】
【预计耗时：3天。】
【警告：融合期间无法修炼，且会散发特殊气息，可能引起他人注意。】

陆沉苦笑。

三天。

刚好是宗门小比的日子，也刚好是和王超的生死战。

系统这破任务，简直是在玩他。

但下一秒，一行新的字浮现——

【检测到宿主处境危险，开启'新手保护'：融合期间，任何练气期以下攻击无法破防。】
【另外，赠送新手大礼包 x1，是否立即开启？】

陆沉的眼睛亮了。

……

（后续：开启礼包获得保命底牌，三天后生死战惊险获胜，正式踏上至尊之路）

## 写作技巧分析

### 1. 开篇抓人 ✅
- 用"死过一次"制造悬念
- 用细节（檀香味、腥甜）增强画面感
- 节奏极快，三句话进入核心冲突

### 2. Show, Don't Tell ✅
- ❌ "陆沉很愤怒" → ✅ "他甚至能闻到对方袖口飘来的檀香味"
- ❌ "系统很强大" → ✅ 用具体数据（至尊神体、1000积分）

### 3. 节奏控制 ✅
- **紧张场景**（被杀死）→ 短句、短段落
- **抒情场景**（查看系统）→ 稍长句式，详细描写
- **悬念结尾** → 留钩子，促使追更

### 4. 情绪曲线 ✅
```
低落（死亡）→ 疑惑（复活？）→ 惊讶（系统！）→ 期待（至尊神体）→ 紧张（三天后生死战）→ 希望（新手保护）
```

### 5. 爽点设计 ✅
- **打脸预告**：王超羞辱陆沉 → 三天后反杀
- **金手指强大**：至尊神体、系统积分、新手保护
- **期待感**：神秘大礼包、保命底牌
