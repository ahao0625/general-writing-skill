# 通用写作技能 (General Writing Skill) v2.0

基于**认知写作学、修辞学、叙事学**的专业写作框架。让每一次写作都有理论支撑、有技巧可执行、有标准可量化。

---

## 理论基础

### 认知写作学核心原理
- **双重编码理论**：文字 + 意象并行，增强记忆（例："他跑了" → "他像一只被猎犬追赶的兔子，拼命奔跑"）
- **认知负载理论**：控制信息密度，避免读者超载（高密度信息和轻松阅读交替）
- **情绪记忆原理**：情绪事件记忆留存率是普通信息的3倍（设计情绪高点）
- **读者认知模型**：预测读者会如何接收、处理、记忆你的内容

### 修辞学体系
- **亚里士多德三类诉求**：理性诉求（logos）+ 情感诉求（pathos）+ 人格诉求（ethos）
- **中国古典修辞**：比（比喻）、兴（联想）、赋（铺陈）
- **现代叙事修辞**：隐喻、转喻、提喻、反讽、悖论

### 叙事学框架
- **热奈特叙事话语**：叙事时间（倒叙/预叙）、叙事焦距（零焦距/内焦距/外焦距）
- **三幕式结构**：建置（25%）→ 对抗（50%）→ 解决（25%）
- **英雄之旅**：出发 → 启蒙 → 回归（12个阶段）

## 核心原则

### 1. 🧠 认知分析优先
**动笔前必须完成的5个分析维度**：
- **读者模型**：目标读者的背景知识、认知偏好、情绪敏感点是什么？
- **认知目标**：希望读者读完后得到什么？（信息/情绪/行动）
- **情绪地图**：设计读者情绪曲线（平静 → 好奇 → 紧张 → 释放 → 回味）
- **记忆点设计**：读者会记住哪3个关键点？
- **认知阻力**：哪些内容可能造成理解障碍？如何降低阻力？

### 2. ✍️ 修辞精准为王
**文字要经得起修辞学检验**：
- **动词中心主义**：一个精准动词 > 形容词+副词组合
  - ✅ "他瞥了一眼手表" → ❌ "他快速地、紧张地看了一眼他的手表"
- **Show, Don't Tell 进阶版**：
  - 用**行为**表达情绪：❌ "他很生气" → ✅ "他猛地站起，椅子在地板上划出刺耳的声响，拳头攥得指节发白"
  - 用**环境**烘托情绪：❌ "她很悲伤" → ✅ "窗外的雨不知何时停了，屋里却还是一片潮湿的阴冷"
  - 用**隐喻**深化情绪：❌ "他很高兴" → ✅ "喜悦像气泡水一样在他胸口往上冒，堵不住，也不想堵"
- **五感立体描写**：视觉、听觉、嗅觉、触觉、味觉 + **内心感官**（情绪、记忆、联想）
- **节奏控制**：句长变化（紧张场景用3-7字短句，抒情场景用15-25字长句）

### 3. 📐 信息架构为基
**好的结构让认知更顺畅**：
- **金字塔原理**：结论先行，以上统下，归类分组，逻辑递进
- **认知漏斗**：吸引注意 → 建立共识 → 打破认知 → 提供方案 → 行动号召
- **信息密度梯度**：高密度（数据、观点）和低密度（故事、描写）交替，避免疲劳
- **节奏蓝图**：明确标记哪里加速、哪里减速、哪里停顿

### 4. 🔍 量化质检为尺
**写完后用标准评分，而非感觉**：
- 逻辑性（0-10）：因果链是否完整？有没有逻辑跳跃？
- 文笔（0-10）：精准度、画面感、节奏感是否达标？
- 节奏（0-10）：信息密度是否合理？情绪曲线是否清晰？
- 共鸣度（0-10）：目标读者能否产生"我也是这样想的"的感觉？
- 记忆点（0-10）：读者能记住几个关键点？

## 工作流程

### 阶段一：认知分析 🧠
**目标**：建立完整的读者模型和认知策略

**执行步骤**：

1. **读者画像分析**：
   - 背景知识：他们已经知道什么？不知道什么？
   - 认知偏好：喜欢故事型还是逻辑型？喜欢具体还是抽象？
   - 情绪敏感点：什么话题/场景容易引发他们的情绪反应？

2. **认知目标设定**：
   - 信息层：希望读者**知道**什么？
   - 情绪层：希望读者**感受**到什么？
   - 行动层：希望读者**做**什么？

3. **情绪地图设计**：
   - 绘制读者情绪随时间变化的曲线
   - 标记情绪高点（爽点/泪点/笑点）
   - 标记情绪低点（铺垫/压抑/困惑）
   - 确保情绪释放点在高潮位置

4. **记忆点设计**：
   - 用"3的法则"：人类短期记忆只能记住3-4个要点
   - 设计3个核心记忆点（金句/场景/数据）
   - 通过重复、对比、情感强化记忆点

5. **认知阻力排查**：
   - 列出可能造成理解障碍的概念/术语/逻辑
   - 设计降低阻力的方法（类比、举例、可视化）

**输出**：「认知策略文档」，包含读者画像、认知目标、情绪地图、记忆点、认知阻力排查表。

---

### 阶段二：结构架构 📐
**目标**：设计符合认知规律的内容框架

**执行步骤**：

1. **选择结构模型**：
   - **小说章节**：引子（5%）→ 发展（35%）→ 高潮（30%）→ 转折（20%）→ 悬念（10%）
   - **议论文**：吸引注意（10%）→ 建立共识（20%）→ 打破认知（30%）→ 提供方案（30%）→ 行动号召（10%）
   - **叙事文**：时间顺序 / 空间顺序 / 逻辑顺序 / 认知顺序（从已知到未知）
   - **营销文案**：AIDA升级版（吸引注意 → 激发兴趣 → 建立信任 → 制造欲望 → 消除顾虑 → 促成行动）

2. **规划信息密度梯度**：
   - 高密度段落（数据、观点、论证）→ 低密度段落（故事、描写、抒情）
   - 避免连续3段以上高密度内容
   - 避免连续3段以上低密度内容（会显得拖沓）

3. **设计节奏蓝图**：
   - 用"加速-减速-停顿"控制阅读节奏
   - 加速：短句、短段、少修饰（紧张/快节奏场景）
   - 减速：长句、长段、多修饰（抒情/慢节奏场景）
   - 停顿：用空行、分割线、金句制造停顿和思考空间

4. **布置记忆点**：
   - 开头：用悬念/反常识吸引注意（记忆点#1）
   - 中间：用故事/数据深化认知（记忆点#2）
   - 结尾：用金句/行动号召强化记忆（记忆点#3）

5. **设计情绪节拍**：
   - 每章/每节至少1个情绪高点
   - 每3章/每3节1个情绪高潮
   - 情绪高点前要有足够的铺垫和压抑

**输出**：「内容大纲 + 情绪节拍表 + 信息密度图」。

---

### 阶段三：修辞撰写 ✍️
**目标**：用专业修辞技巧生产高质量内容

**执行原则**：

#### A. 开篇要抓人（前3句定生死）
- **小说**：用异常现象/悬念/冲突开篇
  - ✅ "陆沉记得很清楚，他死的那天是晴天。"
  - ✅ "系统提示音响起时，陆沉正被人踩在脚下。"
  - ❌ "陆沉是一个年轻人，他生活在..."（太平、太慢）
- **文章**：用反常识/问题/场景开篇
  - ✅ "你有没有想过，为什么我们明明知道拖延有害，却还是一拖再拖？"
  - ✅ "2024年，中国人均可支配收入3.9万元，但年轻人平均负债12.7万元——钱去哪了？"
  - ❌ "今天我想和大家聊聊拖延症。"（太平）
- **文案**：用痛点场景/问题开篇
  - ✅ "你是不是也经历过这种时刻：明明很努力，月底却还是没钱？"
  - ❌ "我们的产品很好用。"（太硬）

#### B. 主体要扎实（每段一个焦点 + 一个转折）
- **焦点原则**：一段只讲一件事，段首用主题句明确焦点
- **转折技巧**：用"但是"、"然而"、"没想到"、"更可怕的是"制造转折
- **证据支撑**：每个观点都要有证据（数据/案例/故事/对话）
- **节奏变化**：
  - 紧张场景：短句（3-7字）、短段（1-2行）、少修饰
  - 抒情场景：长句（15-25字）、长段（5-8行）、多修辞
  - 对话场景：简洁有力、符合人物性格、推动情节/揭示性格

#### C. 结尾要有力（闭环 or 升华 or 行动）
- **小说**：闭环结尾（回应开篇悬念）+ 留悬念（促使追更）
- **文章**：升华结尾（从具体到抽象，引发思考）+ 行动号召（引导互动）
- **文案**：强化卖点 + 消除顾虑 + 明确下一步（现在就买/立即行动）

#### D. 修辞技巧工具箱
- **比喻**：明喻（像...一样）、暗喻（是...）、借喻（直接用喻体代替本体）
  - 例："时间像一把杀猪刀"（明喻）→ "时间是杀猪刀"（暗喻）→ "杀猪刀又落下了"（借喻）
- **拟人**：让抽象概念具象化、人格化
  - 例："焦虑像一只小猫，时不时伸出爪子挠一下心头"
- **排比**：增强气势，强化记忆
  - 例："他想要的很简单：一处安身的住所，一份稳定的收入，一个温暖的笑容。"
- **对仗**：增强节奏感，提升文采
  - 例："有心栽花花不开，无心插柳柳成荫。"
- **反讽**：制造张力，引发思考
  - 例："他可真'聪明'，把自己的前途都'算计'没了。"
- **悖论**：用矛盾吸引注意，深化主题
  - 例："要想得到自由，先得学会服从。"

#### E. 微观文笔要求
- **精准**：删掉所有可以删掉而不影响意思的词
  - ✅ "他跑了" → ❌ "他开始快速地移动他的双腿，朝着前方奔跑而去"
- **简洁**：能用10个字说清楚，不用20个字
  - ✅ "茶杯在托盘上轻轻晃动，发出细碎的碰撞声" → ❌ "他感到很紧张"
- **有画面感**：让读者能看到、听到、感受到
  - ✅ "她的笑容像初春的阳光，融化了心底积压了一个冬天的寒冰" → ❌ "她笑得很温暖，他感到很感动"
- **有情绪感**：文字要能传递情绪，而非陈述情绪
  - ✅ "他盯着手机屏幕，微信对话框里的'对方正在输入...'闪了又闪，最终归于沉默" → ❌ "他很失落"

**输出**：完整的内容正文 + 修辞手法标注（自选）。

### 阶段四：量化质检 🔍
**目标**：用标准评分体系确保质量

**质检清单（量化评分）**：

#### 1. 逻辑性（0-10分）
- [ ] 因果链是否完整？（A→B→C，没有跳跃）
- [ ] 有没有以偏概全？（个例→普遍结论）
- [ ] 有没有偷换概念？（关键词含义前后不一致）
- [ ] 时间线/空间线是否清晰？
- **评分标准**：
  - 9-10分：因果完整，无逻辑漏洞，读者能轻松跟上
  - 7-8分：逻辑基本完整，有1-2处小跳跃
  - 5-6分：有明显逻辑漏洞，需要读者自己补全
  - 0-4分：逻辑混乱，因果不清

#### 2. 文笔（0-10分）
- [ ] 精准度：有没有啰嗦/空洞的表达？
- [ ] 画面感：能不能在读者脑海中形成画面？
- [ ] 节奏感：句长变化是否合理？
- [ ] 修辞：有没有恰当地使用修辞手法？
- **评分标准**：
  - 9-10分：精准、有画面感、节奏好、修辞自然
  - 7-8分：文字通顺，但缺乏亮点
  - 5-6分：有啰嗦/空洞表达，画面感弱
  - 0-4分：文字晦涩，难以理解

#### 3. 节奏（0-10分）
- [ ] 信息密度：高密度和低密度是否交替？
- [ ] 情绪曲线：有没有起承转合？
- [ ] 阅读流畅度：会不会让读者感到疲劳？
- **评分标准**：
  - 9-10分：节奏张弛有度，情绪曲线清晰
  - 7-8分：节奏基本合理，但有些地方拖沓或仓促
  - 5-6分：节奏单一，读者容易疲劳
  - 0-4分：节奏混乱，该快不快，该慢不慢

#### 4. 共鸣度（0-10分）
- [ ] 目标读者能否产生共鸣？
- [ ] 有没有触动读者的情绪敏感点？
- [ ] 有没有"我也是这样想的"的感觉？
- **评分标准**：
  - 9-10分：强烈共鸣，读者觉得"你懂我"
  - 7-8分：有共鸣，但不强烈
  - 5-6分：共鸣点不明显
  - 0-4分：无法引起共鸣，甚至引起反感

#### 5. 记忆点（0-10分）
- [ ] 有没有金句？
- [ ] 有没有令人印象深刻的场景/数据/故事？
- [ ] 读者看完能记住几个关键点？
- **评分标准**：
  - 9-10分：有3个以上强记忆点
  - 7-8分：有1-2个记忆点
  - 5-6分：记忆点不明显
  - 0-4分：没有记忆点，看完就忘

#### 6. 综合评分 + 修改建议
- **综合分** = (逻辑性×0.2 + 文笔×0.3 + 节奏×0.2 + 共鸣度×0.2 + 记忆点×0.1)
- **修改建议**：针对得分最低的维度，给出具体修改方案

**输出**：量化质检报告（含分项评分、综合分、修改建议）+ 修订版本（如有必要）。

## 特殊场景处理（专业升级版）

### 场景一：网文小说写作
**基于叙事经济学的专业规范**：

#### 爽点设计理论
- **成就感爽点**：努力 → 回报，付出 → 收获（例：修炼多年，一朝突破）
- **报复感爽点**：被欺辱 → 逆袭打脸（例：曾经看不起主角的人，现在跪求原谅）
- **认可感爽点**：被忽视 → 被重视（例：曾经不被看好的废材，现在人人敬仰）
- **满足感爽点**：欲望得到满足（例：财富、权力、爱情、自由）

#### 情绪曲线设计
- **章内情绪曲线**：开篇（平静）→ 发展（紧张）→ 高潮（释放）→ 结尾（悬念）
- **跨章情绪曲线**：3章一个小高潮，10章一个大高潮
- **情绪压制技巧**：在高潮前压制情绪（让主角受挫、失败、误会），让高潮更爽

#### 留存机制设计
- **章末悬念**：在章节末尾留下未解之谜/未完成的动作
- **期待感设计**：让读者想知道"接下来会发生什么"
- **情感投入**：让读者对主角产生情感依恋（同情、认同、期待）

#### 节奏控制规范
- **铺垫（20%）**：建置场景、人物、冲突
- **发展（30%）**：冲突升级、情节推进
- **高潮（30%）**：情绪释放、问题解决（或升级）
- **余韵（20%）**：收尾、过渡、埋下新悬念

#### 网文特殊技巧
- **金手指设计**：系统、传承、重生、穿越（给主角非常规优势）
- **打脸节奏**：每3-5章一个小打脸，每10-15章一个大打脸
- **女角色出场**：避免花瓶，要有独立性格和作用
- **反派设计**：避免脸谱化，要有合理动机和魅力

### 场景二：文章/博客写作
**基于认知漏斗模型的专业规范**：

#### 认知漏斗模型
1. **吸引注意（10%）**：标题 + 首段前三行，用悬念/反常识/场景吸引
2. **建立信任（20%）**：用数据、案例、故事证明专业性，建立读者信任
3. **打破认知（30%）**：提出反常识观点，打破读者固有认知，引发好奇
4. **提供价值（30%）**：给出具体可操作的方法/方案/建议
5. **行动号召（10%）**：引导评论、分享、关注、购买

#### SEO优化规范
- **标题优化**：含关键词，25-35字，吸引点击
- **小标题优化**：H2/H3标签，含关键词，清晰分层
- **内链外链**：相关文章内链，权威来源外链
- **可读性优化**：段落3-5行，多用空行，多用列表

#### 互动性设计
- **穿插提问**：让读者思考，增强参与感
- **用"你"**：第二人称，增强代入感
- **案例故事**：用具体案例/故事，避免说教
- **引导评论**：文末提问，引导读者留言

---

### 场景三：文案写作
**基于Cialdini影响力原则的专业规范**：

#### 六大影响力原则应用
1. **互惠原理**：先给价值，再要行动（例：免费试用 → 购买）
2. **承诺一致**：引导小承诺，逐步升级（例：免费注册 → 付费订阅）
3. **社会认同**：用数据、案例、名人背书（例："已有10万+用户使用"）
4. **喜好原理**：建立相似感、亲和力（例："我和你一样，曾经也..."）
5. **权威原理**：展示专业资质、认证（例："XX认证"、"XX推荐"）
6. **稀缺原理**：限时、限量、独特价值（例："仅剩3席"、"倒计时24小时"）

#### AIDA升级版模型
- **Attention（吸引注意）**：标题 + 首图 + 前三行
- **Interest（激发兴趣）**：痛点场景 + 共鸣
- **Trust（建立信任）**：资质 + 案例 + 数据
- **Desire（制造欲望）**：价值展示 + 对比（使用前vs使用后）
- **Remove Fear（消除顾虑）**：售后保障 + 退款承诺
- **Action（促成行动）**：明确的下一步指令 + 紧迫感

#### 文案特殊技巧
- **痛点精准**：一针见血地指出问题（例："你是不是也..."）
- **价值具象**：把抽象价值变成具体场景（例："省下的时间，够你多陪孩子玩一小时"）
- **证明有力**：用数据、案例、前后对比、用户评价
- **行动明确**：告诉读者具体要做什么（例："点击购买"、"立即注册"）

## 修辞技巧工具箱（快速查阅）

| 修辞手法 | 定义 | 使用场景 | 示例 |
|---------|------|---------|------|
| 明喻 | 用"像"、"如"等比喻词 | 需要形象化抽象概念 | "时间像一把杀猪刀" |
| 暗喻 | 不用比喻词，直接说"是" | 需要更强的修辞力度 | "时间是杀猪刀" |
| 借喻 | 直接用喻体代替本体 | 需要简洁有力的表达 | "杀猪刀又落下了" |
| 拟人 | 把物当作人来写 | 需要让抽象概念具象化 | "焦虑像一只小猫，时不时伸出爪子挠一下心头" |
| 排比 | 三个以上结构相似的句子/短语 | 需要增强气势、强化记忆 | "他想要的很简单：一处安身的住所，一份稳定的收入，一个温暖的笑容。" |
| 对仗 | 上下句结构对称、意义相关 | 需要增强节奏感、提升文采 | "有心栽花花不开，无心插柳柳成荫。" |
| 反讽 | 用正话反说表达讽刺 | 需要制造张力、引发思考 | "他可真'聪明'，把自己的前途都'算计'没了。" |
| 悖论 | 用矛盾的表达深化主题 | 需要吸引注意、引发思考 | "要想得到自由，先得学会服从。" |
| 反复 | 重复使用同一词语/句子 | 需要强化情绪、增强节奏 | "他跑了，跑了，头也不回地跑了。" |
| 设问 | 自问自答 | 需要引导读者思考 | "钱重要吗？当然重要。但比钱更重要的，是赚钱的能力。" |

## 节奏控制技巧（快速查阅）

### 句长控制
- **紧张场景**：3-7字短句，制造紧迫感
  - 例："他跑了。拼命地跑。不敢回头。"
- **抒情场景**：15-25字长句，营造氛围
  - 例："暮色像一块柔软的灰蓝色绸缎，轻轻地覆盖在小城上空，家家户户的灯火次第亮起，像星星落在了人间。"
- **信息场景**：7-15字中句，清晰传达
  - 例："2024年，中国人均可支配收入3.9万元，但年轻人平均负债12.7万元。"

### 段落长度控制
- **紧张场景**：1-2行短段，加速节奏
- **抒情场景**：5-8行长段，减速节奏
- **信息场景**：3-5行中段，平稳节奏

### 标点符号控制
- **句号**：减速，表示停顿
- **逗号**：减速但保留连贯，表示短暂停顿
- **顿号**：加速，表示并列
- **破折号**：制造停顿和转折，吸引注意
- **省略号**：制造悬念和期待，表示未尽
- **问号**：引发思考，增强互动
- **感叹号**：增强情绪，慎用（每千字不超过3个）

## 情绪设计技巧（快速查阅）

### 情绪曲线设计
- **平静 → 好奇 → 紧张 → 释放 → 回味**（经典情绪曲线）
- **压抑 → 压抑 → 压抑 → 爆发 → 释放**（网文爽文曲线）
- **困惑 → 探索 → 理解 → 领悟 → 升华**（知识分享曲线）

### 共鸣点设计
- **共同经验**：找到目标读者的共同经历（例：上班被骂、月底没钱、异地恋）
- **共同情绪**：找到目标读者的共同情绪（例：焦虑、无奈、期待、失落）
- **共同价值观**：找到目标读者的共同价值观（例：努力会有回报、善良的人有好报）

### 爽点/泪点/笑点设计
- **爽点设计**：压抑（90%）→ 释放（10%），压抑越久，释放越爽
- **泪点设计**：失去、遗憾、无奈、感动（用细节打动，而非直接说"悲伤"）
- **笑点设计**：反差、意外、自嘲、夸张（避免硬挠笑点，要自然）

## 量化质检标准（详细版）

### 逻辑性评分标准
- **9-10分**：因果完整，无逻辑漏洞，读者能轻松跟上。有预防性反驳（提前回应可能的质疑）。
- **7-8分**：逻辑基本完整，有1-2处小跳跃，但不影响理解。
- **5-6分**：有明显逻辑漏洞，需要读者自己补全。有以偏概全/偷换概念的倾向。
- **0-4分**：逻辑混乱，因果不清，读者无法理解论证过程。

### 文笔评分标准
- **9-10分**：精准、有画面感、节奏好、修辞自然。读者能在脑海中形成画面，情绪被触动。
- **7-8分**：文字通顺，但缺乏亮点。有些地方可以更精准/更简洁。
- **5-6分**：有啰嗦/空洞表达，画面感弱。有些地方"告诉"多于"展示"。
- **0-4分**：文字晦涩，难以理解。大量堆砌形容词/副词。

### 节奏评分标准
- **9-10分**：节奏张弛有度，情绪曲线清晰。信息密度合理，读者不感到疲劳。
- **7-8分**：节奏基本合理，但有些地方拖沓或仓促。情绪曲线不够清晰。
- **5-6分**：节奏单一，一直快或一直慢。信息密度不合理，读者容易疲劳。
- **0-4分**：节奏混乱，该快不快，该慢不慢。情绪曲线平坦无起伏。

### 共鸣度评分标准
- **9-10分**：强烈共鸣，读者觉得"你懂我"。精准触动目标读者的情绪敏感点。
- **7-8分**：有共鸣，但不强烈。有些地方能引起共鸣，有些地方不能。
- **5-6分**：共鸣点不明显。读者读完后没有特别的感觉。
- **0-4分**：无法引起共鸣，甚至引起反感。脱离目标读者的真实经验。

### 记忆点评分标准
- **9-10分**：有3个以上强记忆点（金句/场景/数据）。读者看完能记住关键信息。
- **7-8分**：有1-2个记忆点。但不够强，容易被忘记。
- **5-6分**：记忆点不明显。读者看完后印象不深。
- **0-4分**：没有记忆点，看完就忘。

## 使用示例（升级版）

### 示例一：写玄幻小说章节（系统流）

**用户输入**：
```
帮我写一章玄幻小说，主角是陆沉，刚刚获得系统，要写他发现系统的过程，要有悬念和爽点
```

**执行流程**：

1. **认知分析**：
   - 读者模型：18-30岁男性，喜欢玄幻/仙侠，有"逆袭"、"打脸"情节偏好
   - 认知目标：信息层（系统功能）→ 情绪层（惊喜、期待）→ 行动层（追更）
   - 情绪地图：疑惑（0%）→ 惊讶（30%）→ 狂喜（60%）→ 期待（90%）→ 悬念（100%）
   - 记忆点：①"叮——"系统提示音 ②系统面板的逆天功能 ③第一个任务的高风险高回报
   - 认知阻力：系统流读者熟悉套路，需要创新点

2. **结构架构**：
   - 开篇（5%）：陆沉被欺辱的场景，情绪低落
   - 转折（10%）："叮——"系统提示音突然出现
   - 发展（30%）：查看系统面板，发现逆天功能
   - 高潮（40%）：系统发布第一个任务，奖励丰厚但风险极高
   - 悬念（15%）：陆沉犹豫是否接受任务，章末留悬念

3. **修辞撰写**：
   - 开篇用感官描写（听觉、视觉、触觉）表现陆沉的困境
   - 系统出现用突然的感官冲击（声音、文字浮现在眼前）
   - 查看系统用具体的数据和功能描述（不用模糊的"很厉害"）
   - 结尾用悬念和期待（任务有风险，但奖励诱人）

4. **量化质检**：
   - 逻辑性：8分（系统出现有伏笔，但不算特别新颖）
   - 文笔：9分（画面感强，节奏好）
   - 节奏：9分（张弛有度，情绪曲线清晰）
   - 共鸣度：8分（能引起目标读者共鸣，但不算特别强烈）
   - 记忆点：9分（有3个强记忆点）
   - 综合分：8.5分，建议微调开篇，增加系统出现的创新点

### 示例二：写文章（分析类）

**用户输入**：
```
写一篇关于"为什么很多人明明很努力却还是穷"的文章
```

**执行流程**：

1. **认知分析**：
   - 读者模型：22-35岁打工人，有相似困惑，希望得到新视角
   - 认知目标：信息层（努力与贫穷的关系）→ 情绪层（共鸣、启发）→ 行动层（反思 + 改变）
   - 情绪地图：困惑（0%）→ 共鸣（20%）→ 惊讶（40%）→ 理解（60%）→ 启发（80%）→ 行动（100%）
   - 记忆点：①"战术勤奋 vs 战略懒惰" ②"努力是穷人的毒品" ③"选择 > 努力 > 运气"
   - 认知阻力：读者可能有防御心理（"我努力没错"），需要共情而非说教

2. **结构架构**：
   - 引子（10%）：一个具体案例（"我有个朋友..."）
   - 分析1（25%）：努力的方向错了（战术勤奋 vs 战略懒惰）
   - 分析2（25%）：系统的问题（阶层固化、起点、运气）
   - 分析3（25%）：如何破局（选择、杠杆、长期主义）
   - 结尾（15%）：重新定义"努力"和"成功"，引导行动

3. **修辞撰写**：
   - 开篇用具体案例 + 数据，引发共鸣
   - 每个观点都用故事/数据支撑，避免说教
   - 语言接地气，用"你"增强代入感
   - 适当使用修辞手法（比喻、排比、反问）增强感染力

4. **量化质检**：
   - 逻辑性：9分（因果完整，有数据支撑）
   - 文笔：8分（通顺，但有些地方可以更有文采）
   - 节奏：8分（基本合理，但有些地方可以更紧凑）
   - 共鸣度：9分（强烈共鸣，读者觉得"你懂我"）
   - 记忆点：9分（有3个强记忆点）
   - 综合分：8.6分，建议增加更多具体案例，增强说服力
