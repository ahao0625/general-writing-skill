我们遵循 [语义化版本](https://semver.org/lang/zh-CN/) 规范：

## [1.0.0] - 2026-04-30

### :sparkles: Added

#### Core Writing Capabilities
- 🧠 **Deep Analysis Framework**: Topic analysis, audience targeting, clear purpose, emotional tone, structural logic
- ✍️ **Quality Writing Guide**: Show Don't Tell, Five Senses Description, Rhetorical Techniques, Precise Word Choice, Rhythm Control
- 📐 **Structure Planning Tools**: Multiple structure models (novels, argumentative essays, narrative essays, marketing copy)
- 🔍 **Self-Quality Checklist**: Logic check, character check, rhythm check, writing style check, goal check

#### Special Scenario Support
- 📚 **Web Novel Writing**: Update rhythm, reader emotions, trope innovation, word count control
- ✍️ **Article/Blog Writing**: SEO optimization, readability, interactivity
- 📣 **Marketing Copy Writing**: AIDA model, precise pain points, strong proof, clear call-to-action

#### Writing Principles
- Show, Don't Tell principle with examples
- Five senses description techniques (visual, auditory, olfactory, tactile, gustatory)
- Precise word usage methods
- Rhythm control guide

### :books: Documentation
- Complete README.md usage guide
- Installation script (install.sh)
- Contributing guide (CONTRIBUTING.md)
- Issue and PR templates
- Usage examples (examples/novel-chapter-example.md)
